🧩

Editor CodeMirror 6

Abas, syntax highlight neon, busca e autosave com restauração de sessão. Seu código, sempre salvo.

🐧

Terminal Linux real

VM QEMU headless com glibc completo. Rode binários originais ARM64 — sem porte, sem emulação de libc.

🔀

Git / GitHub

Clone, commit, push, branches e diff direto na UI via JGit. O projeto e o repositório nunca se desencontram.

🗂️

Workspace único

Editor e terminal operam na mesma camada de arquivos via virtio-9p. Edite e rode sem copiar nada.

Toolbox

🤖

IA nativa

Por que QEMU (e não "mais um Termux")?

Termux usa a libc e o kernel do próprio Android. O Phantom-Code não.

TermuxPhantom-Code
libcBionic (quebra libs desktop)glibc completo (binários originais)
KernelMesmo do AndroidGuest isolado (systemd funciona)
Ferramentas de IAPrecisam de porteRodam nativas (Ollama, llama.cpp…)
